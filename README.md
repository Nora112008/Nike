# 👟 Nike Landing Page

A clean and responsive landing page inspired by **Nike**, built to practice modern web design, layout structuring, and interactive front-end development.


## 🔗 Live Demo
[View Live Website](https://nora112008.github.io/Nike/
)

---

## ✨ Features

- **Responsive Design:** Works smoothly on desktop, tablet, and mobile screens.
- **Interactive UI:** Dynamic elements powered by JavaScript (such as mobile navigation menu and product interactions).
- **Clean Layout:** Organized sections including a hero banner, featured shoes, and footer.
- **Smooth Hover Effects:** Transitions on buttons and product cards.

---

## 🛠️ Built With

- **HTML5** — Page structure and semantic tags.
- **CSS3** — Styling, Flexbox/Grid layouts, and responsive media queries.
- **JavaScript (ES6)** — DOM manipulation and interactive features.

---

## 🎯 What I Learned

- Structuring a clean webpage using semantic HTML.
- Building responsive layouts with CSS Flexbox and Grid.
- Adding interactivity and handling events using vanilla JavaScript.
